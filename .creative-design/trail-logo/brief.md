# Trail Logo 设计 Brief

## 主题与商品
- 主题：为本地优先的桌面 AI Agent 工作台设计应用图标（App icon）。
- 商品：Trail（原包名 pi-desktop，应用 ID net.aiuo.pi-desktop，窗口标题 Trail）。
- 无实体商品；核心对象是品牌图形标识。

## 品牌事实
- 定位：local-first · model-agnostic · plugin-powered 的桌面 Agent 工作台，面向开发者与高级用户。
- 气质：克制、专业、冷静、几何极简、开发者密度、可信赖；深色模式优先，浅色可用。
- 视觉基线：中性炭灰表面、中性灰阶（非蓝 slate）、一个低饱和中性强调色；扁平、无装饰渐变、无 3D 塑料感。
- 旧标参考：docs/image/readme/logo.png，浅色圆角方底 + 深色几何抽象 P 形 + 圆点，单色几何、圆角、极简；新标延续单色几何与圆角语言。

## 准确名称
- 品牌名：Trail（英文，首字母大写，其余小写）。
- 本轮产物：独立图形 App 图标（favicon / 应用图标受限场景），按用户锁定提示词不出现文字；含 "Trail" 字标的标准组合主标待图形方向确认后派生。

## 任务范围
- 方向 B：足迹 / 圆点轨迹 图形标（已出候选 v1）。
- 方向 C：字母 T + 弯曲小径 + 底部分叉岔路 图形标（本轮候选）。
- 本轮只出图形标候选；不做规范页、不做 Mockup、不做多状态变体。

## 创意概念与风格
- 概念：Trail = 小径、足迹、轨迹；用一组由近及远、由大到小的圆点（抽象脚印）沿一条对角轨迹退向远方，表达"行走留下的轨迹 / Agent 工作旅程 / 持久会话路径"。
- 母题：动势轨道与开放环 + 极简几何符号；一个主母题，无第二个装饰母题。
- 线条风格：实心圆润圆点 + 极细对角虚线引导；端点圆、转角圆润、闭合实心、黑白节奏清楚、干净矢量边。
- 配色：1 个中性炭灰墨色 + 1 个小面积低饱和中性强调色（最后一个实心终点圆点）；其余圆点为半透明灰；背景纯白。颜色角色 ≤ 3，无渐变。

## 构图
- 1:1 方形，圆角方形图标底板（中性浅灰或纯白，与旧标一致的 macOS 风格圆角方形容器）。
- 圆点轨迹从左下近大，向右上远小，沿约 45° 对角线排列 3–4 个；最后（最远/最上）一个为实心强调色终点，其余为半透明灰。
- 主体居中，四周充足安全留白；小尺寸剪影仍可辨认。

## 必须保留 / 禁止
- 保留：几何圆润、扁平、纯符号化、无写实脚掌、单色 + 一个强调色、留白干净。
- 禁止：3D 立体、塑料/金属/玻璃质感、彩虹或蓝紫渐变、霓虹发光、写实照片、复杂纹理、场景插画、人物动物、文字拼写、TM/®/©、水印、杂乱背景、多个图标堆叠、发丝微孔细节。

## 画幅与质量
- 1:1，2048×2048；平面矢量风、边缘锐利、对比清晰；纯白均匀背景。

## 候选 C：字母 T · 小径分叉（本轮）

### 创意概念
- 概念：既是字母 T（Trail 首字母），也是一条向前延伸的路；T 的横笔保持水平稳定，竖笔化为微微弯曲的小径，竖笔底部自然分叉成两条细线（岔路），呼应 Trail / 路径 / Agent 多步规划与分支选择。
- 母题：几何字母标 + 动势轨道；一个主母题，无第二个装饰母题。

### 造型与线条
- 顶部横笔水平、稳定、粗笔画；竖笔由横笔中点向下，带轻微自然弯曲，像一条小径向前延伸。
- 竖笔底部自然分叉为两条等粗细线，左右岔开，端点圆头；整体几何对称、重心居中。
- 粗笔画、圆角端点、圆角转角；实心块面，干净矢量边；黑白剪影在小尺寸下仍可辨认为 T。

### 配色
- 主体中性炭灰实心；分叉处（岔路口）点缀唯一小面积低饱和强调色（与方向 B 同一克制暖赭橙，保持候选家族一致）；颜色角色 ≤ 3，无渐变。

### 构图与画幅
- 1:1，2048×2048；macOS 风格浅中性灰圆角方形底板置于纯白均匀背景；T 形主体居中，四周充足安全留白。

### 必须保留 / 禁止
- 保留：粗笔画、圆角端点、几何对称、扁平矢量、开发者工具风、无渐变无立体阴影。
- 禁止：3D、塑料/金属/玻璃、发光、渐变、写实道路、树木场景、文字拼写、TM/®/©、水印、复杂背景、多图标堆叠、发丝微孔。
- 画面不出现完整 "Trail" 字标；仅以 T 字形符号作为图形标。

### 造型与线条

### 构图与画幅
- 1:1，2048×2048；深炭灰中性圆角方形底板（本轮按用户提示词使用深炭灰底板），纯白均匀背景，居中构图，充足留白，可缩放、干净锐利。

## 候选 E：Trail 纯文字字标（本轮）

### 创意概念
- 概念：标准纯字标，准确拼写 "Trail"；在现代无衬线骨架上，把字母 i 的点替换为一枚小径节点小圆点，呼应路径 / 会话节点，其余笔画保持干净。

### 字体与造型
- 现代几何人文无衬线，字重中等偏粗；字距收紧，基线平稳，字母等高；左对齐横向排版。
- i 的点改为一枚圆润实心节点圆点（与字身同色）；a 保持正常字腔，不做多余变形。
- 无描边、无衬线装饰、无斜体、无连体。

### 配色
- 单色中性炭灰；不使用强调色、不使用渐变；纯白背景。

### 构图与画幅
- 16:9 横版，2048×1152；纯白均匀背景，字标靠左、上下左右充足安全留白；矢量排版，干净锐利，可缩放。

### 文字与验收
- 画面唯一文字为准确英文 "Trail"（T 大写，r/a/i/l 小写），逐字不得增删、错拼或变形；不出现其他字母、口号、标签、水印、TM/®/©。
- 禁止：3D、阴影、渐变、发光、描边外框、纹理、场景、装饰图形、多色。

## 候选 F：参考图风格 · 黑底板灰度路径条（本轮）

### 风格参考
- 参考图：D:\proma\resources\icon.png（已上传短链 https://aka.doubaocdn.com/s/BS2Dt3VsYF），仅作风格参考，不复刻其具体竖条数量、间距与轮廓。
- 继承风格机制：纯黑超圆角方形（squircle）底板；内部一组圆角矩形竖条；颜色由白到深灰依次灰度过渡；竖条长度依次递减、轻微向右扇形倾斜；纯扁平、无描边、无阴影、无文字、黑白灰单色。

### 概念转译
- 把竖条解读为小径上一段段前行的路径 / 步道分段：最左端最亮最高（起点），向右依次变暗、变短、轻微倾斜，象征由近及远的轨迹与推进节奏；不出现写实道路、树木或场景。

### 造型与配色
- 6 根左右圆角矩形条，圆角端点统一；灰度从纯白经浅灰、中灰到近黑，每根纯色、无填充渐变；无第二个彩色。
- 居中排布，四周充足安全留白；小尺寸剪影仍能读出扇形灰度节奏。

### 画幅与禁止
- 1:1，2048×2048，纯黑底板置于纯白画布背景；无文字、无 TM/®/©、无水印、无 3D、无发光、无场景、无装饰纹样。

### 候选 F-v2：从小到大（本轮翻转）
- 基于 F-v1 成品翻转竖条顺序：从左到右由小到大、由暗到亮——最左端最矮、最暗（近黑），向右依次变高、变亮，最右端最高、最亮（纯白）；灰度由近黑经深灰、中灰、浅灰到白；长度递增，仍保持轻微向右扇形倾斜与统一圆角。
- 其余风格机制与禁止项同 F-v1：纯黑超圆角底板、扁平黑白灰、无描边阴影文字、1:1 纯白画布背景。
